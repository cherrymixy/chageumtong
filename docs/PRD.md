## 0. 한 줄 정의

**안전하게 달린 거리만큼 포인트가 쌓이는 차 안의 저금통.**
주행이 끝나면 이번 주행을 분석해 포인트를 적립하고, 그 포인트로 현대차 디지털 상품(테마·기능 구독·차량용품)을 사거나 근처 사용처(충전소·대리점·블루핸즈)를 찾아 바로 길안내를 받는다.

- 앱 이름: **차금통** (차 + 저금통)
- 캐릭터: 당근(=포인트)을 먹으며 달리는 **유니콘**
- 대상 화면: Pleos Connect 에뮬레이터 v2.1.0 (Automotive, 2560×1440, 160dpi, 가로)

## 2. 핵심 루프

```
[대기] 기어 P, 정차
   │  기어 D + 속도 > 0
   ▼
[주행 중] 거리·시간 누적, 위반 이벤트 감지 → "이번 주행으로 적립될 포인트" 실시간 증가
   │  속도 0 + 기어 P
   ▼
[주행 종료] [주행 분석하고 적립하기] 버튼 활성화
   │  탭
   ▼
[분석 결과] +NP 적립 완료 · 안전운전 비율 · 미적립 구간 설명 → [확인하기]
   │
   ▼
[대기] 총 포인트·월간 통계 갱신 → 상점/지도에서 포인트 사용
```

**원칙:** 적립은 "주행을 마무리하는 의식"이다. 주행 중엔 보기만, 정차 후에 행동한다.

## 3. 포인트 규칙 (확정)

| 항목 | 규칙 |
|---|---|
| 적립 단위 | **주행 1회** (기어 D 출발 → 정차+P 종료) |
| 기본 적립 | **안전운전 거리 1km = 1P**, `floor(안전운전거리 km)` |
| 안전운전 거리 | 총 이동거리 − 미적립 구간 거리 |
| 미적립 구간 | 위반 이벤트가 발생한 지점 기준 **±250m (총 500m)** 구간. 겹치면 합집합 |
| 안전운전 비율 | `안전운전거리 / 총 이동거리 × 100` (반올림, %) |
| 안전점수 (홈 표시) | 안전운전 비율과 동일한 값 (점) |
| 칭찬 문구 | 95↑ "참 잘했어요!" · 85–94 "좋아요!" · 70–84 "조금만 더!" · 70↓ "다음엔 더 안전하게" |
| 최소 주행 | 이동거리 0.3km 미만이면 적립 없이 종료 (분석 버튼 비활성, 안내 문구) |
| 적립 시점 | 분석 화면 진입 시 확정·저장 (중복 적립 방지: 세션 ID당 1회) |

### 위반 이벤트 3종

| 이벤트 | 칩 문구 | 판정 규칙 | 데이터 출처 |
|---|---|---|---|
| 과속 | `{n}km 과속` | 속도가 해당 구간 제한속도 +10km/h 초과 상태로 3초 이상 | 속도: **Vehicle SDK 실데이터** / 제한속도: 데모 경로 데이터(실주행 시 기본 60km/h) |
| 급커브 미감속 | `급커브 구간 미감속` | 커브 구간 진입 시 속도 > 40km/h | 데모 경로의 커브 구간 정의 (핸들 각도 API는 실차 미지원) |
| 안전거리 미확보 | `안전거리 미확보` | 데모 이벤트 주입만 | ADAS SDK 실차 미지원 → "ADAS 연동 예정"으로 기획서에 명시 |

각 이벤트는 `{type, atKm, segmentStartKm, segmentEndKm, location("종로구 21-22" 같은 라벨), title, description}`을 가진다.
설명 문구 예: "급커브 구간에서 충분한 감속 없이 주행한 것이 감지되어 해당 구간의 포인트가 적립되지 않았어요. 커브 진입 전 미리 속도를 줄여 안전하게 주행해 주세요."

## 4. 데이터 출처 전략 (Real + Demo)

심사위원은 차를 운전할 수 없다. 그래서 **같은 파이프라인에 두 개의 입력원**을 꽂는다.

```
VehicleDataSource (interface)  ── speedMps: Flow, gear: Flow
 ├─ PleosVehicleDataSource   ← Vehicle SDK 실데이터 (에뮬레이터 adb / Virtual Console / 실차)
 └─ DemoVehicleDataSource    ← 25km 시나리오를 약 90초로 압축 재생
         ↓
DriveSessionEngine (거리 적분, 위반 판정, 상태머신)  ← 입력원 몰라도 됨
```

- **데모 주행**: 대기 상태 홈에 작은 `▶ 데모 주행` 칩. 탭하면 25km 시나리오 재생(7km 급커브, 11km 과속 10km, 13.5km 안전거리 미확보). 종료 시 자동으로 기어 P.
- 데모 중에도 화면·로직은 실주행과 100% 동일 경로를 탄다 (분기는 입력원뿐).
- 실 SDK 입력은 `checkXXXCapability`로 지원 여부를 먼저 확인하고, 미지원이면 조용히 Demo만 노출.

## 6. 화면 명세

### 6.1 홈 (`95:2142`)
**좌측 메인 카드 (이번 주행)**
- "이번 주행으로 적립될 포인트" + 큰 숫자 `{N}P` (주행 중 실시간 증가)
- 도시 일러스트 + 달리는 유니콘 (주행 중 달리는 애니메이션, 대기 중 정지) + 길 위 당근
- 진행 레일 0–25km: 파란 채움 = 이동 거리, 주황 = 미적립 구간, 차 아이콘 = 현재 위치. 25km 초과 시 레일 스케일 자동 확장(최대값 = ceil(거리/5)*5)
- 하단: [주행 분석하고 적립하기] · 주행거리(km) · 주행시간(분) · 안전점수(점)
- 대기 상태: 지난 주행 값이 아닌 0으로 리셋, `▶ 데모 주행` 칩 노출

**우측 상단 — 총 적립 포인트 카드 (파랑)**: 총 포인트 `14,560P` · "이번 달 +{n}P 적립" · [포인트 사용하기] [적립 내역 확인하기]

**우측 중단 2카드**
- 이번 달 안전운전 거리 `{km}` + 반원 게이지(월 안전운전 비율 %) + 칭찬 배지
- 이번 달 주행거리 `{km}` + 이번 주 월–일 막대 (오늘 막대 강조색)

**우측 하단 — 광고 배너 캐러셀** (5장, 자동 넘김 5초, 점 인디케이터, `Ad` 배지). 정적 이미지.

### 6.2 주행 분석 결과 (`95:2638`, `95:2689`)
- 상단 파란 헤더: `+{N}P` + "적립이 완료됐어요!" + 당근 일러스트
- "이번 주행 분석": 반원 게이지 `{비율}%` + 칭찬 배지
- 이동거리 / 안전운전 거리 / 주행시간
- "포인트 미적립 구간" + 안내문 + 이벤트 칩 가로 스크롤 (선택 칩 = 주황 채움, 나머지 = 회색)
- 우측 지도: 경로 폴리라인(파랑) + 미적립 구간(주황) + 선택 이벤트 말풍선 카드(위치 라벨·제목·설명)
- 하단 [확인하기] → 홈. 위반 0건이면 미적립 섹션 대신 "모든 구간 적립 완료!" 상태
- 기본 선택: 첫 번째 이벤트

### 6.3 지도 — 포인트 사용처 (`95:2751`)
- 좌측 리스트: 검색바(로컬 필터) · 장소 카드(이미지·이름·분류·차량 소요시간·거리·영업중·즐겨찾기 별·[길안내 시작])
- 우측 지도: **정적 지도 이미지 + 핀**(장소 위치는 정규화 좌표), 현재 위치 = 유니콘 마커
- 필터 칩: 충전소 / 대리점 / 블루핸즈 (다중 토글)
- [길안내 시작] → `NaviHelper.requestRoute(목적지)` 호출. 실패/미지원 시 토스트 "내비게이션으로 안내를 시작할 수 없어요"

### 6.4 상점 (`95:2870`)
- 좌상단 토글: **SHOP**(현대샵 차량용품) / **BLUE LINK**(디지털 상품: 디스플레이 테마·기능 구독 FoD)

### 화면 스케일 규칙
앱은 화면 전체(2560×1440)가 아니라 Pleos 홈의 **오른쪽 앱 영역 1682×1210dp**에 뜬다 (2026-11-13 실측, `dumpsys activity`).
Figma 프레임 1700×1184와 거의 같으므로 → **세로 기준 스케일 `s = 1210/1184 ≈ 1.022`**. 가로 차이(−18dp)는 **좌측 메인 카드가 흡수**. 토큰 파일 `Dimens.kt`의 `fig(x) = (x * s).dp` 헬퍼로 일괄 적용.

## 12. 결정 사항 (STEP 0에서 확정, 2026-11-13)

| # | 항목 | 확정 |
|---|---|---|
| D1 | 위반 구간 길이 | ±250m |
| D2 | 실주행 제한속도 | NaviHelper `onCurrentRoadSpeedLimit(int)` 값 우선, 없으면 60km/h |
| D3 | 데모 재생 | 실제 90초 재생, 샘플 시각은 압축(약 ×17) → 화면·엔진에는 약 25분 / 25km 주행으로 기록. 속도값은 실제 km/h 그대로 |
| D4 | 레일 최대값 | 25km 기본, 초과 시 5km 단위 확장 |
| D5 | 시드 데이터 규모 | 4주, 주 4–6회 주행 |

- 데모 과속 이벤트: 제한 50km/h 구간에서 70km/h → 칩 `20km 과속` (규칙상 +10km/h "초과"여야 하므로 10km는 불가)
- 데모 예상 결과: 25km − 미적립 1.5km = 23.5km → **23P / 94% "좋아요!"**
- 속도는 Vehicle SDK 2.3.2에 API가 없어 AAOS `CarPropertyManager`의 `PERF_VEHICLE_SPEED`(m/s)로 읽는다. 기어는 Vehicle SDK `Gear`. (호환성 문서가 AAOS 프로퍼티 사용을 안내함)
- 기어에는 `checkXXXCapabilities` API가 없음 → 첫 조회 실패 시 미지원 처리.
